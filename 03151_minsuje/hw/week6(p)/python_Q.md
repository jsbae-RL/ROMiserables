# 문제 2: Seaborn 데이터셋을 활용한 통계 분석 및 시각화
- 사용 라이브러리: numpy, statsmodels, SciPy, Seaborn, matplotlib

## 문제 설명
- Seaborn에서 제공하는 'tips' 데이터셋을 이용하여 통계 분석을 수행한다.
- total_bill과 tip의 관계를 분석하고, 이를 활용한 선형 방정식을 세운다.
- SciPy를 사용하여 선형 방정식을 풀고, statsmodels를 활용한 회귀 분석을 수행한다.
- 팁을 최대로 받을 수 있는 total_bill 금액을 찾는 최적화 문제를 설정하고 해결한다.
- Seaborn과 matplotlib을 활용해 데이터 분포를 시각화한다.
## 요구 사항
- 1.tips 데이터셋을 불러오고 기본 통계를 출력한다.
- 2.total_bill과 tip의 평균 및 분산을 구한다.(numpy 기초연산)
- total_bill과 tip 간의 단순 선형 관계를 가정하고, ax+b=y 형태의 선형 방정식을 새워 a와 b를 구한다.
- SciPy를 활용한 최적화 하는데 optimize(optimize에 안배운 함수사용한거라라 검색 해보시거나 제거 참조만 하고 넘어가셔도 됩니다. 본 답변이랑 test에 두가지 optimize로 푸는 방법이 그대로 있습니다. 그냥 해봤어요. 제방법 말고도 gpt에 물어보면 더 간단한 코드도 있으니 참조 하시길 바라요.)등을 이용하여 풀어라.
- total_bill과 tip의 관계를 산점도로 나타내고 예상 최대팁과 총금액 그리고 선형도를 나타내어 보자.
